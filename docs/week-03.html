Predict the output

Write down what each prints before running it. Then run them.

// 1
int hp = 12;
if (hp > 10) {
    System.out.print("Healthy ");
}
System.out.print("Done");
// 2
int hp = 3;
if (hp > 10) {
    System.out.print("Healthy ");
} else {
    System.out.print("Hurt ");

System.out.print("Done");
// 3
int coins = 50;
if (coins >= 10) {
    System.out.println("Bronze");

Fix the bug

All three compile. All three are wrong. Fix each one and write a sentence saying what was happening.

Bug 1

Always denies you, even when you type dragon.

String password = input.next();

if (password == "dragon") {
    System.out.println("Access granted");
} else {
    System.out.println("Access denied");
}
Hint

== asks whether two things are the same object in memory. For text you want to know whether the letters match, which is a different question.

Bug 2

A 95 should be an A. It prints D.

int score = 95;

if (score >= 60) {
    grade = "D";
} else if (score >= 70) {
    grade = "C";
} else if (score >= 80) {
    grade = "B";
} else if (score >= 90) {
    grade = "A";
}
Hint

A chain stops at the first branch that is true. Is 95 greater than or equal to 60?

Bug 3

Says Respawning... at full health.

int hp = 100;

if (hp <= 0)
    System.out.println("You died.");
    System.out.println("Respawning...");
Hint

Without braces, an if controls exactly one line. The indenting is a lie. Java ignores it.

Problems

1. Level checker

Ask for XP, print the level.

XPLevel
1000 or more4
500 to 9993
100 to 4992
under 1001
Example run 
Enter your XP: 620
Level 3
Hint 1

One if / else if / else chain, not four separate if statements. Four separate ones would print several levels at once.

Hint 2

Start from the biggest number and work down. Then each branch only needs one comparison.

2. Magic 8-Ball

Ask a yes-or-no question, ignore the answer, print one of at least five replies at random.

Example run 
Ask me anything: Will I pass the test?
Signs point to yes.
Hint 1

(int) (Math.random() * 5) gives you a whole number from 0 to 4.

Hint 2

Store that number in a variable first, then use a chain to turn it into a reply. If you call Math.random() inside every branch you get a different number each time.

3. One-shot guessing game

Ask the player's name. Pick a secret number from 1 to 10. Take one guess and say whether it was too high, too low, or right. If they were off by exactly 1, say they were close. Always reveal the answer.

Example run 
Your name: Sam
Guess 1-10, Sam: 7

Too high!
But you were close.
It was 6.
Hint 1

(int) (Math.random() * 10) + 1 gives 1 to 10.

Hint 2

"Close" is a separate question from "too high". Answer them with two if blocks, not one chain.

Hint 3

Reading a name and then a number in one program is where nextLine() misbehaves. nextInt() leaves the Enter key in the buffer, so a later nextLine() reads that instead of waiting.

4. Text adventure

Write a dungeon scene with a real choice. A door on the left and one on the right, leading to different rooms with different text. Change the player's HP or gold in at least one room, then print their status.

Example run 
A corridor splits. Left or right? left
A goblin clips you for 10.
HP 90, gold 0.
Hint

Compare text with .equals() or equalsIgnoreCase(), never ==. Use equalsIgnoreCase() so Left and left both work.

5. Leap year, optional

Ask for a year and say whether it is a leap year. Divisible by 4 is a leap year, unless it is also divisible by 100, unless it is also divisible by 400. So 2024 is, 1900 is not, and 2000 is.

Example run 
Year? 1900
Not a leap year.
Hint 1

year % 4 == 0 asks whether a year divides by 4 exactly.

Hint 2

A nested if works and is easier to get right. A single condition with && and || also works and is very satisfying once it clicks. Try the nested one first.

Rules

  1. Braces on every if, even when the body is one line.
  2. No semicolon after the closing ) of an if.
  3. Indent inside braces. Java does not care. Whoever reads it does.
  4. Name, date and one sentence at the top of every file.
  5. Only what you have been taught: if / else if / else, Scanner, printf, casting. No loops, no switch, no methods other than main.
  6. Stuck for fifteen minutes on one thing? Stop and ask.
