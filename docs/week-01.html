Variables and types

A variable is a box you put a value in. Every box has a name and a type.

Boxes

Think of a variable as a labelled box. You put a value in it, and later you can look inside using the label.

Two rules that catch people:

  • Names are case-sensitive. score and Score are two different boxes.
  • Every box has a type, so Java knows what kind of thing is going in it.

The five types

TypeHoldsExample
StringWordsString name = "Adi";
intWhole numbers, positive or negativeint age = 16;
doubleNumbers with decimalsdouble cost = 0.37;
booleantrue or false, nothing elseboolean isRaining = false;
charExactly one characterchar initial = 'B';
Quotes matter

String uses double quotes "like this". char uses single quotes 'B'. Swapping them is a compile error.

The format

int age = 16;
 ↑    ↑    ↑  ↑
type name value ends the line

Names can use a-z, A-Z, 0-9 and _. No spaces, and they cannot start with a number.

Every statement ends with a semicolon. It tells Java the line stops there.

3. Break the rules

Try each of these, one at a time, and read the error you get:

  • Put a decimal into an int.
  • Put two letters into a char.
  • Name a variable 2cool.

You are learning what the error messages mean, which is most of debugging.
