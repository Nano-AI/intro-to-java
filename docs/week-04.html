The trade

You have been copying the same lines twice, once for each fighter. A method lets you write them once and call them twice. When the formula is wrong, you fix it in one place.

Methods go inside the class, next to main, never inside it.

public class Squares {
    public static void main(String[] args) {
        System.out.println(square(7));
    }

    public static int square(int n) {
        return n * n;
    }
}
Order does not matter

Java finds square whether you write it above or below main. Put your methods after main so the reader sees the program first.

Parameters

A parameter is a variable the method is handed when it is called.

public static void greet(String who) {
    System.out.println("Hello, " + who + "!");
}
You writewho becomesIt prints
greet("Sam")"Sam"Hello, Sam!
greet("Adi")"Adi"Hello, Adi!

The name who only exists inside the method. Nothing outside can see it.

Returning a value

Two kinds of method. The difference is what sits before the name.

DoesYou call it
voidActs, hands nothing backon its own line
int, double, StringWorks something out and hands it backwhere a value would go
 
greet("Sam");                    // void, a whole statement

int answer = square(7);          // returns, so it goes on the right of =
System.out.println(square(7));   // or straight into a println
The one that catches everyone

return ends the method immediately. Anything written after it never runs.

4. Battle Sim, without the copy and paste

BattleScore.java

In Battle Sim you typed the combat formula twice, once per fighter. Put it in a method and call it twice.

Example 
Fighter 1 strength, armor, stamina? 80 60 55
Fighter 2 strength, armor, stamina? 70 90 40

Fighter 1 combat = 68.8
Fighter 2 combat = 67.5
Hint 1

The method takes three int values and hands back a double, so it starts public static double warriorScore(int strength, int armor, int stamina).

Hint 2

Keep the 4.0. All three parameters are whole numbers, so dividing by 4 would throw the decimal away. Same trap as week 2.

Hint 3

Now change the formula to divide by 5.0 and run it. Notice you only had to edit one line for both fighters. That is the whole point of the week.

Rules

  1. Methods go inside the class, beside main, never inside it.
  2. Every method that promises a type must return that type on every path.
  3. Keep a method short. If it will not fit on your screen, it is doing too much.
  4. Name it for what it does. square, not doIt.
  5. Name, date and one sentence at the top of every file.
  6. Stuck fifteen minutes on one thing? Stop and ask.
What this unlocks

Every assignment from here on can use methods, and the rule that banned them is gone. Going back and rewriting Battle Sim with them is worth an hour.
