Intro to Java

Each week has a page to read, a zip to download, and problems with hints when stuck.

  1. Week 0
    • Running the first program Open a file in jGRASP, compile it, run it, and read an error message.
  2. Week 1
    • Variables and types Boxes that hold values. String, int, double, boolean, char.
  3. Week 2
    • Maths and user input Operators, casting, the division trap, and asking questions with Scanner.
  4. Week 3
    • Conditionals if / else if / else. Predict output, fix three bugs that compile fine, then write five programs.
    • Battle Sim project Two fighters, two score formulas, one winner. Do this after the problems above.
  5. Week 4
    • Methods Write something once and use it anywhere. Parameters and return values.

How to work

  1. Download the week's zip and unzip it.
  2. Open a file in jGRASP, then Build → Compile and Build → Run.
  3. Get one piece working and run it before adding the next. Do not write the whole thing and then compile.
  4. Try a problem before opening its hints.

Never used jGRASP? Week 0 walks through it.
