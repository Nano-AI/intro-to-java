Intro to Java

Each week has a page to read, a zip to download, and problems with hints when you get stuck.

  • WEEK 0 Running your first program Open a file in jGRASP, compile it, run it, and read an error message.
  • WEEK 1 Variables and types Boxes that hold values. String, int, double, boolean, char.
  • WEEK 2 Maths and user input Operators, casting, the division trap, and asking the user questions with Scanner.
  • WEEK 3 Conditionals if / else if / else. Predict some output, fix three bugs that compile fine, then write five programs.
  • WEEK 3 / PROJECT Battle Sim Two fighters, two score formulas, one winner.

How to work

  1. Download the week's zip and unzip it.
  2. Open a file in jGRASP, then Build → Compile and Build → Run.
  3. Get one piece working and run it before adding the next. Do not write the whole thing and then compile.
  4. Try a problem before opening its hints.

Never used jGRASP? Week 0 walks through it.
