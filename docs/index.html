Install

  1. Install VS Code 1.96 or newer.
  2. Install the Language Support for Java by Red Hat extension, and have a JDK available (a free build such as Eclipse Temurin works; Java 21 is recommended).
  3. Download the VSIX above, then in VS Code open Extensions → … → Install from VSIX and choose the downloaded file.
  4. Open a learning folder and run Pip: Open Course from the Command Palette.

What's inside

  • Lesson (interactive model)
  • Quiz (prediction)
  • Code in Student.java
  • Save & run

Each unit runs that loop in a real Java editor with automated checks, plain-language error notes, and output graphics or a 3D robot replay. Three robot projects close out the course: an obstacle detour, a cargo delivery, and a hoop shot. 35 learning units, 39 coding parts (30 console, 9 robot), across six modules:

  • Start with Java
  • Make work repeat
  • Build reusable actions
  • Respond to the world
  • Work with collections of data
  • Put it all together
