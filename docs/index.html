Install

  1. Download the installer above and open it.
  2. Drag Pip Workshop into the Applications folder.
  3. Open Pip Workshop from Applications. The first time, macOS may say it cannot check the app: open System Settings → Privacy & Security, choose Open Anyway, then open the app again.
  4. If macOS says the app is damaged and can’t be opened, open Terminal, run xattr -cr "/Applications/Pip Workshop.app", then open the app again. This clears the download mark; Pip is safe to open.
  5. Choose Start the first lesson. Code and progress save automatically in the .pip-java folder in the home folder.

Updating

To update, download the newest installer and drag it into Applications again, replacing the old copy. Code and completed lessons stay in .pip-java, so earlier progress stays checked off.

What's inside

  • Explore (interactive model)
  • Quiz (prediction)
  • Code in Student.java

Each unit runs that loop in a built-in Java editor with live error underlines, code suggestions, automated checks, plain-language error notes, and output graphics or a 3D robot replay. Three robot projects close out the course: an obstacle detour, a cargo delivery, and a hoop shot. 35 learning units, 39 coding parts (30 console, 9 robot), across six modules:

  • Start with Java
  • Make work repeat
  • Build reusable actions
  • Respond to the world
  • Work with collections of data
  • Put it all together
